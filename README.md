# 🌍 AI Trip Planner

AI Trip Planner is a full-stack web application that helps users plan trips, manage travel budgets, track expenses, and generate personalized itineraries using Artificial Intelligence.

## 🚀 Features

* User Registration and Login
* JWT Authentication
* Create and Manage Trips
* AI-Based Itinerary Generation
* Budget Planning
* Expense Tracking
* Route Optimization
* Responsive User Interface

## 🛠️ Technologies Used

### Frontend

* React.js
* JavaScript
* HTML
* CSS
* Axios

### Backend

* Spring Boot
* Spring Security
* JWT
* Spring Data JPA

### Database

* PostgreSQL

### AI Integration

* Google Gemini API

## ⚙️ Setup Instructions

### Backend

cd backend
mvn spring-boot:run


### Frontend

cd frontend
npm install
npm run dev

## 🔑 Environment Variables

Create a `.env` file and add:

GEMINI_API_KEY=your_api_key
JWT_SECRET=your_secret_key
